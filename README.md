# Ajustador de Strings

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue)](https://www.python.org/)  
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## Descrição

O **Ajustador de Strings** é um projeto em Python desenvolvido para **automatizar a correção e padronização de dados textuais** em planilhas Excel ou bancos de dados. Ele é ideal para equipes de análise de dados que precisam organizar informações de forma consistente antes de realizar análises, relatórios ou dashboards.

O projeto demonstra conhecimentos em:

- Manipulação de planilhas com **Pandas** e **OpenPyXL**.  
- Processamento de texto, incluindo normalização, remoção de acentos e caracteres especiais.  
- Fuzzy matching para identificar correspondências aproximadas entre palavras ou expressões.  
- Automação de correção de dados repetitivos e criação de colunas adicionais com resultados ajustados.  
- Aplicação de estilos em células para destacar inconsistências ou itens que exigem revisão manual.

---

## Funcionalidades

- Leitura e escrita de planilhas Excel (.xlsx)  
- Normalização de strings para padronização de dados  
- Correção automática com fuzzy matching e regras definidas pelo usuário  
- Criação de novas colunas com os valores corrigidos  
- Destacar visualmente valores que precisam de revisão  
- Suporte para diferentes tipos de projetos (delivery, apps, CRM, entre outros)
